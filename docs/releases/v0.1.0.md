# Hivemind v0.1.0

Collective, durable memory for coding agents. This release supports local MCP
and bounded single-node team deployments, with native macOS and Linux downloads.

## Download and install

Choose your platform archive below, or use the installer:

```sh
curl -fsSL https://github.com/mingley/hivemind/releases/download/v0.1.0/install.sh -o /tmp/hivemind-install.sh
HIVEMIND_VERSION=v0.1.0 sh /tmp/hivemind-install.sh
export PATH="$HOME/.local/bin:$PATH"
hivemind --version
```

macOS 13+: `macos-aarch64` for Apple Silicon, `macos-x86_64` for Intel.
Linux (glibc 2.35+): `linux-x86_64` or `linux-aarch64`; also usable in WSL2.
Archives include `hivemind`, `hivemindd`, MIT `LICENSE`, and binary checksums.
The installer checks the published archive hash before extracting/installing.
See the attached `QUICKSTART.md` for a one-minute test and agent setup.

## Production hardening

- Authenticated tenant grants across HTTP, MCP and gRPC; machine identities
  cannot self-declare human trust. MCP sessions are bound to their principal.
- Complete, durable backup/restore including evidence blobs.
- Erasure propagates cleanup errors, uses atomic segment replacement, and
  resumes incomplete tombstoned erasures before accepting work.
- Blocking daemon workers on macOS, persistent client buffering, and one
  shared HTTP/gRPC store registry.
- Native package smoke tests plus fmt, Clippy, workspace tests, format/property
  tests, a 1,000-cycle SIGKILL soak, and LazyFS cache-loss tests gate publication.

## Performance

Scoped queries filter irrelevant documents before BM25 scoring. Compact
postings, shared applicability maps, and optional lifecycle allocations reduce
memory. Sparse log seek anchors accelerate claim expansion and change cursors
without changing the persistent format.

Same-host synthetic 20k-claim comparison: scoped recall p95 improved from
0.315 ms to ~0.17 ms; global recall p95 from 2.93 ms to ~1.00 ms. Replay-only
RSS fell from 209.1 to 117.0 MiB at 100k claims, and from 1,675.8 to 882.2 MiB
at 1M. These are workload-specific measurements, not an absolute memory bound.
Reproducible methodology and default-capacity latency results live in
https://github.com/mingley/hivemind/blob/v0.1.0/docs/performance.md.

Default admission: 100k claims per store. Provision at least 512 MiB per active
store plus request/backup overhead. Single-node recovery is supported; automatic
HA, external identity-provider federation, and end-to-end agent productivity
claims are outside this release's guarantees. The 50 MB laptop target remains
unmet at 100k. Embeddings stay optional.
