# Hivemind v0.2.0

Collective, durable memory for coding agents. `v0.2.0` adds sub-millisecond
Turn-0 hook briefing (`hivemind brief --hook-json`), adaptive top-card
auto-expansion in `recall`, cross-repo citation artifact snapshotting and
hydration, a loopback Streamable HTTP MCP bridge on `hivemindd`, and faster
scoped recall / concurrent reads.

## Download and install

Choose your platform archive below, or use the installer:

```sh
curl -fsSL https://github.com/mingley/hivemind/releases/download/v0.2.0/install.sh -o /tmp/hivemind-install.sh
HIVEMIND_VERSION=v0.2.0 sh /tmp/hivemind-install.sh
export PATH="$HOME/.local/bin:$PATH"
hivemind --version
```

macOS 13+: `macos-aarch64` for Apple Silicon, `macos-x86_64` for Intel.
Linux (glibc 2.35+): `linux-x86_64` or `linux-aarch64`; also usable in WSL2.
Archives include `hivemind`, `hivemindd`, MIT `LICENSE`, and binary checksums.
The installer checks the published archive hash before extracting/installing.
See the attached `QUICKSTART.md` for a one-minute test and agent setup.

## What's new in v0.2.0

- **Turn-0 Hook Briefing (`hivemind brief` / `--hook-json`):** Ranks active
  scoped + global memories against the submitted prompt in under a millisecond,
  excludes `Untrusted` (`origin=external`), `Retracted`, `Superseded`, and
  context-mismatching claims, drops weak distractor overlaps (`< 0.40 × top_score`),
  and emits prompt-ready `additionalContext` JSON with zero extra MCP round-trips.
- **Adaptive Top-$k$ Auto-Expansion (`expand_top = 3` in `recall`):** Keeps the
  in-memory `ClaimRow` keydir compact (`280` chars; `0` extra RAM at 100k/1M
  claims) while reloading full untruncated `statement`, structured `payload`
  fields, `cite_locs`, and `quotes` on demand from the log for top trusted hits.
- **Cross-Repo Citation Snapshots (`BlobStore` + Missing-File Hydration):**
  `HiveMcp::remember` hashes and snapshots small cited workspace files (`<= 8 KiB`,
  secret-checked, `Origin::RepoFile`) as content-addressed artifacts, and
  `Store::brief` hydrates them automatically when absent in a downstream
  repository (zero token overhead when the file exists locally).
- **Loopback HTTP MCP Bridge (`hivemindd --mcp-http`):** Exposes authenticated
  Streamable HTTP MCP (`0600` bearer token at `<store>/mcp-http.token`) on
  loopback for SSH-tunneled remote dev environments sharing a local store.
- **Daemon & Engine Hardening:** Scoped recall pre-filtering and lock-free
  reads during writes, `SIGHUP`-resilient detached daemons (`--detached`),
  automatic MCP client reconnect on daemon restart, and per-session actor
  isolation.
- **End-to-End Outcome Benchmark ([Crucible](https://github.com/mingley/crucible)):**
  Across 144 paired `claude-sonnet-5.5` trials (`latent-memory-v1` +
  `coding-memory-v1`), `hivemind` achieved **48 / 48 (`100.0%` Pass@1 & Pass^3)**
  and strictly Pareto-dominated static `AGENTS.md` (`91.7%` Pass@1, **-34.7%**
  Cost-per-Success at `p < 0.0001`, **-15.9%** wall time at `p = 0.0023`) and
  no-memory baselines (`50.0%` Pass@1, McNemar `p = 0.0005`).
